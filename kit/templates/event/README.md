This is our shared workspace for the event. Everything here is a git history:
every contact and note records who logged it and when, and nothing gets
overwritten.

## What's in here

- `prep/`: who's in the room, why they matter, and how we split it up.
- `speakers/`: researched profiles of speakers and panelists.
- `contacts/`: one file per person we meet. Each teammate's touchpoints append to it.
- `notes/`: session takeaways, themes from the floor, ideas, to-dos.
- `slides/`: photos of slides by session (`NN.jpg`), each with notes (`NN.md`)
  and a session `README.md` that tells the talk slide by slide.
- `drafts/`: post drafts (tweets, threads, LinkedIn, blog), never posted from here.
- `flash-cards/`: the shared deck, one file per term (acronyms, vocabulary,
  concepts, market standards) that came up at the event.
- `exports/`: CRM import files, for when the CRM connection isn't working.

## How to use it from Claude or Codex

Ask in plain words. For example:

- "What's the plan for today?" or "Who should I find at the reception?"
- Send a speaker card: "Who is this?"
- Send a badge photo: "Log this person. We talked about …; send them our deck."
- "Who has the team met from Schneider Electric?"
- At the end: "Move today's contacts into the CRM." Records are proposed first; nothing is written to the CRM until you approve.

## House rules

- **Log it within the hour.** A name with one line of context beats a perfect note tomorrow.
- **Search before logging.** Someone else may already have met them.
- **Priority:** A = pursue now · B = follow up after the event · C = nice to know.
- **Never invent details.** If the badge doesn't show an email, leave it out.

## Contacts and reference lists

- `Contacts__Met.csv` (root): everyone the team **met and logged**, one row
  each, regenerated by the server from `contacts/*.md` on every
  `log_contact` and `mark_crm_synced` (`contacts_csv` rebuilds it on
  demand). Phones in E.164. Don't edit it by hand; edit the contact file.
- Attendee lists, sponsor lists, rosters: **reference, not contacts.** They
  go in `prep/`, and being on one never makes someone a contact.

## Naming files you add

Rename every added file to **Title-Case BEM**: `Block__Element--Modifier`,
words joined by hyphens, each word capitalized. The block is usually the
event, the element is what the file is:

- `7x24-Exchange-Fall-2026__Attendee-List.csv`
- `7x24-Exchange-Fall-2026__Sponsor-List--Gold-Tier.csv`
- `7x24-Exchange-Fall-2026__Brochure.pdf`

Never keep a download's original name (`attendees (3).csv`). Files the
server writes keep the names the server gives them.
