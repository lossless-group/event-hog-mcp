## Why Care?

Writes only ever added or appended, so a misspelled name or a wrong email from a badge photo stayed wrong, and someone logged by mistake stayed on the list. Each event was already a git repo, but nobody outside the chat could open it.

## What's New?

- **`correct_contact`** replaces the fields you name, needs a reason, and adds a dated line with the old values. If the name or company changes, the file is renamed. The CSV and the CRM database follow.
- **`remove_contact`** first shows what would go (touchpoints, who logged them, whether it's already in HubSpot). It only removes when called again with the same path. If teammates logged touchpoints too, only an admin can remove it.
- **`clone_link`** returns a read-only `git clone` command and a `git pull` to refresh, good for one hour. Open the folder as a vault in Obsidian.
- **Faster calls.** Every call now clones only the latest commit. In the two-person simulation, total server time went from 149s to 96s.
- **eventhog.cc** says how it runs on Cloudflare Artifacts, and brings back the two ways to run it: use ours, or deploy your own.

## Under the Hood

- Both fixes and removals are git commits by the caller, so the earlier version is always in the history.
- `remove_contact` matches observations by source with `substr` rather than `LIKE`, since D1 rejects long `LIKE` patterns.
